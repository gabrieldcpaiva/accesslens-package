# AccessLens Outreach Templates
**Use cases:** LinkedIn DM, cold email, community posts  
**Tone:** Direct, evidence-first, not pushy

---

## Template 1 — LinkedIn DM

```
[Name],

I looked at [site/company] and it looks like a mission-critical site with real public traffic.

Most accessibility audits miss the barriers that actually cause lawsuits because they don’t test real journeys.

I’m running AccessLens pilots this week: scoped audit, human-approved repair, independent verification, before/after evidence.

Only need 3 sites. Want a 20-minute scoping call?
```

---

## Template 2 — Cold Email

```
Subject: Your accessibility audit probably missed this

Hi [Name],

Automated scanners catch about 30–40% of meaningful accessibility failures. The rest show up in real journeys—keyboard, form submission, screen-reader flow.

AccessLens closes that loop:

1. Scoped audit with reproducible evidence
2. Human triage and prioritization
3. Approved-only repair
4. Independent verification
5. Before/after evidence package

No production changes without approval. No hollow certification claims.

Want a 20-minute scoping call? I’m taking 3 pilot engagements this week.

[Dylan / AccessLens]
```
