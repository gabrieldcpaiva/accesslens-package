# AccessLens Demo
**Goal:** Provide a stable, repeatable demonstration of AccessLens end-to-end.

## Contents
- `before.html` — barrier-seeded demo site
- `after.html` — repaired demo site
- `evidence.json` — structured findings, repair, verification, and ledger

## How to run
Open `before.html` and `after.html` in a browser. Use only keyboard to walk the journeys:
1. Open dropdown with keyboard
2. Complete contact form
3. Submit invalid form and observe focus behavior
