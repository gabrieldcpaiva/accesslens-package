| Field | Value |
|-------|-------|

---

## 2) Core Truth
Accessibility scanners already exist. **AccessLens closes the loop:**
1. discovery with evidence
2. human judgment at decisive moments
3. approved-only repair
4. independent verification
5. verifiable before/after output

Trust comes from visible human decisions and passing-after-failing replay, not from claiming automated perfection.

---

## 3) Competition MVP Scope
Focus tightly on **one golden path**:
- **Keyboard navigation journey**
- **Contact-form completion journey**
- **Semantic controls inspection**

Everything else is secondary polish.

### Required demo moments
1. Agent proposes scope → human approves testing boundary
2. Reproducible barrier with evidence
3. Human triage/severity decision
4. Repair proposal → human approves patch
5. Sandbox apply → independent rerun
6. Before/after evidence dashboard
7. One intentional failure/rejection path to prove trustworthiness

---

## 4) What To Show Judges
